# BG-RU: Мой болгарский словарь (FastAPI version)

Образовательный веб-тренажер для изучения болгарского языка и "ложных друзей переводчика".

## О проекте
Я выбрал его, потому что мне было интересно изучить болгарский язык, при этом по нему достаточно мало обучающих ресурсов, особенно в сравнении с такими популярными языками как английский, французский и так далее.

"BG-RU: Мой болгарский словарь" позволяет пользователям вести персональный список иностранных слов с переводом и примерами использования. Главная особенность — интерактивный тренажер, который помогает закреплять знания через тестирование.

### Основные функции
- **Личный кабинет:** Регистрация и авторизация пользователей.
- **Управление словарем:** Добавление, редактирование и просмотр личного списка слов.
- **Валидация данных:** Встроенная проверка на использование кириллицы (болгарский и русский языки).
- **Тренажер (Quiz):** Выбор случайных карточек для проверки знаний.
- **Интуитивный интерфейс:** Современный дизайн на базе Bootstrap 5.

## Технический стек
- **Backend:** Python 3.10+, FastAPI
- **ORM:** SQLAlchemy
- **База данных:** SQLite
- **Frontend:** HTML5, Jinja2, Bootstrap 5

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/alexzhelyapov1/digital-department-fastapi-project
   cd digital-department-fastapi-project
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

3. Настройте переменные окружения:
   Скопируйте файл `.env.example` в `.env` и при необходимости измените значения:
   ```bash
   cp .env.example .env
   ```
   *Примечание: Приложение содержит дефолтные значения для удобства демонстрации, поэтому этот шаг можно пропустить при первом запуске.*

4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Запустите сервер:
   ```bash
   python run.py
   ```

6. Откройте приложение в браузере по адресу: `http://127.0.0.1:8000/`


В проекте реализованы автоматизированные тесты для проверки основного функционала (регистрация, авторизация, добавление слов, валидация).
